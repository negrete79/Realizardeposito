Leitor de Códigos (ELGIN USB)

Como usar:

1. Conecte o leitor ELGIN no cabo OTG (celular) ou na porta USB do computador.

2. Fique na aba Painel — o campo "Cód Produto" fica selecionado sozinho (refoco automático a cada 0,5s). Preencha Quantidade para bipar vários de uma vez.

3. Bipe o produto: ele entra no carrinho com o BIP de confirmação. A fila interna não deixa perder nenhum bip, mesmo em sequência rápida.

4. Lê código de barras (EAN-13, EAN-8, Code-128, Code-39...) e QR Code com leitor ELGIN 2D — inclusive QR com texto longo: o app procura o código do produto dentro do conteúdo.

Dicas: se o campo perder o foco, o app captura o bip em modo global mesmo assim. No celular o teclado só abre quando você toca no campo — bipar não abre teclado. Sem leitor, use a câmera ou toque no campo, digite o código e pressione Enter.
